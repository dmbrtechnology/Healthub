# Healthub 🩺✨

**Healthub**, yapay zekâ destekli, geliştirici dostu ve modüler mimariye sahip bir sağlık platformudur. Kişiselleştirilmiş sağlık çözümleri sunar, geliştiricilere modern sağlık uygulamaları oluşturmak için eksiksiz bir altyapı sağlar.

## 🚀 Özellikler

- ⚙️ API-first mimari
- 🧠 Yapay zekâ destekli öneri sistemleri
- 🔌 Hazır sağlık veri entegrasyonları (HL7, FHIR, vb.)
- 📊 Gerçek zamanlı sağlık verisi analizi
- 📱 Mobil ve web uygulama desteği
- 🧩 Genişletilebilir modül altyapısı
- 🛡 HIPAA & GDPR uyumlu veri güvenliği

## 🛠 Kurulum

### Geliştirici Ortamı

```bash
# Repo'yu klonla
git clone https://github.com/healthub/healthub.git
cd healthub

# Frontend'i başlat
cd frontend
npm install
npm run dev

# Backend'i başlat
cd ../backend
pip install -r requirements.txt
python main.py
